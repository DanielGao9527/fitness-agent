# 参考资料与运行数据

这个目录区分可随源码发布的参考资料和运行时生成的私人数据。参考文件为 JSON，用户记录存放在数据库，两者互不混用。

| 路径 | 内容与使用方式 |
| --- | --- |
| [knowledge/sources.json](knowledge/sources.json) | 来源、定位、审核日期、适用范围和文字摘要，由本地知识检索读取 |
| [nutrition/reference.json](nutrition/reference.json) | 有出处的食材成分代理、计量口径与假设，供程序核算参考 |
| [training/exercises.json](training/exercises.json) | 动作、目标、器械条件与来源标识 |
| [training/systems.json](training/systems.json) | 训练结构参考、正式组参考及本项目改编说明 |
| `runtime/` | 运行后生成的用户数据库、认证状态、备份和其他私有文件，不提交到 Git |

参考资料不是完整食物数据库、完整课程或个体处方。训练参考笔记与公开网页来源使用不同出处类型；未能核实原始发布者的文字资料不提供虚构原文链接。“已审核”不代表作者身份已核实或拥有完整课程的转载许可。具体边界见[知识来源](../docs/KNOWLEDGE_SOURCES.md)。

修改成分值、动作或结构时，应保留来源与计量口径，同时运行相关目录、推荐和约束测试。未核实的研究候选不随公开版本发布，也不进入运行时索引；缺少可靠来源的候选不能只改状态就进入推荐。

用户数据库路径通过 `FITNESS_DB_PATH` 配置；公共检索索引可从参考 JSON 重建。云端应将持久化数据库和备份放在代码发布目录之外，更新代码时保留用户数据。不要把私人数据移到 [static/](../static/) 或上传到公开仓库。
