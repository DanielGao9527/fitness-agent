# 应用运行时提示词

这些 Markdown 文件是应用功能的一部分：后端在执行指定任务时读取模板，告诉模型应如何理解输入、输出什么结构，以及哪些内容不能自行猜测。

它们是发送给应用内模型的任务约定。给开发工具使用的项目交接记录、私人需求或工作指示不属于本目录。

| 模板 | 作用 |
| --- | --- |
| `coach_understanding.md` | 将自由描述整理为受限的饮食／训练意图及待澄清项 |
| `meal_text.md` / `meal_photo.md` | 识别饮食描述或图片中的食物，缺少份量时保留未知 |
| `nutrition.md` | 对实际饮食作带假设与范围的营养估算 |
| `workout_text.md` / `workout_calories.md` | 整理实际训练描述和消耗估算 |
| `quick_meal.md` | 在允许的候选范围内选择餐次食材 |
| `next_meal.md` / `meal_plan_nutrition.md` | 支持餐单草稿及其营养核对流程 |
| `knowledge_answer.md` | 依据提供的知识片段回答并引用出处 |
| `training_plan.md` | 约定训练草稿结构，具体可执行性由业务层核对 |
| `assistant.md` / `plan.md` | 通用助手与早期计划边界说明；文件存在不代表对应能力全部开放 |

修改提示词时，应同时查看调用它的 [services/](../services/) 模块、[schemas.py](../schemas.py) 和对应测试。当前训练编排主要在本地规则中执行，不能仅修改模板就宣称推荐规则已经改变。

提示词不承担权限控制。用户身份、过敏限制、数值范围、来源有效性和保存行为均由服务端独立校验；不要在模板中放入密钥或真实用户样本。
