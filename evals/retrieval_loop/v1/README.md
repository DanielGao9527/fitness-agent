# 有界检索固定响应回放 v1

24 个自建合成流程，候选引用当前公开来源清单，输入哈希和有效日期在 manifest.json 固定。它检查零命中、证据不足、重复/重排候选、改写越界、数字/时间/否定变化、无效输出、伪造引用、来源撤回、时间上限和不增加第三轮。

这里的“当前”指冻结时版本。运行语料更正后，回放使用[原语料快照](../../corpora/README.md)，保持原字节哈希、流程题目与预期不变；报告明确标记历史语料。当前更正语料不能冒用旧v1清单通过校验，应用也不读取此历史快照。

每例同时运行单轮与两轮策略，读取同一份候选和固定模型输出；判断始终收到原问题。单轮保留原来的“零命中不调用判断”基线，两轮可对第一次零命中请求一次改写。第二次仍无命中或候选仅重排时，不增加判断调用。

~~~powershell
.\.venv\Scripts\python.exe scripts/replay_knowledge_loop.py --output artifacts/knowledge-loop-replay
~~~

无需密钥、网络或私人账号库。索引在临时目录，报告只保留案例 ID、引用 ID、停止原因、模拟调用次数和阶段耗时，不复制原问题或模型原始输出。时间来自虚拟时钟，仅测试截止逻辑；不是线上延迟。

**局限：** 这些输出是为流程分支编写的固定响应，没有独立语义标注；不能据此报告召回率、模型准确率、线上改善或计费收益。两轮给出更多 answered 只说明该固定脚本走到了相应分支。真实问答质量、无依据拒答和费用对照仍待独立题集和显式预算。语义等价检查仍由原问题证据判断负责，后端的词面规则只覆盖有限数字、时间与否定形式。
