## 比较什么

复用当前 `answer_question` 引擎，仅改变 `KnowledgePolicy(max_rounds=1/2)`：

- single：至多一次检索/判断；零候选时沿用原来不判断的行为。
- bounded：首轮缺证据时允许一次改写/重检索；二次仍针对原问题核验证据，最多两次检索/判断。
- 两边同一 qwen3.6-plus、固定日期/公共摘要、jieba、1024 维 text-embedding-v4、每路 20、RRF k=60、45 秒协作式时间预算。案例按序交替哪一侧先运行；不共享查询编码或第一轮模型响应。模型即使温度为 0 也可能波动，小样本不能保证全部差值只来自重检索。

这是当前引擎的轮数消融，不是历史 E3a→E3b 的版本增益；E3a 已有部分两轮能力。本工具直接进入公共知识引擎、使用空档案，不评价主聊天分流、账号额度、私人记忆或整个产品。公开知识向量缓存只读，不触碰私人业务库或发布知识。

## 先计划与复核，不调用模型

```powershell
python scripts/evaluate_knowledge_loop.py --split all
python scripts/evaluate_knowledge_loop.py --prepare-review --split all --output artifacts/e3-review-new
```

默认只验证结构、出处/期限并计算上限，不读取密钥，不按问题执行检索或模型判断；静态范围预检不是语义评测。带 `--vectors` 可只读检查现有公共文档缓存是否完整匹配，不补编码。

开发集混合对照最多 72 次请求（36 判断＋36 查询编码），全部 24 题最多 144 次（72＋72）。这是无额外分流/裁判调用、文档向量已准备情况下的上限，不是实际消费或授权。词法对照单独标记，两版均只用词法时全题最多 72 次判断；不能称线上混合检索效果。

REVIEW.md 给出原问题、候选含义/反例、公开摘要与完整语料入口。labels.json 初始全部 pending，不自动写审核。确认后填写真实复核人、日期与逐题 accepted；更改任何问题会使原复核失效。项目所有者复核不等于外部专家或盲审。

保留反例 `loop-semantic-draft-01`：“一般成年人，肌肉强化活动每周最低要安排几天？”静态上会被现有“安排”词面范围规则拦截，候选标签仍是一般可答资料；没有改写问题或改成拒答标签来刷分。本轮不修改线上范围规则。

## 真实执行需新的明确预算

以下仅说明命令形式，必须先复核标签、落实新预算并准备匹配缓存。原记忆批次累计 64 次已经用完，不能借用：

```powershell
python scripts/evaluate_knowledge_loop.py --live --split dev --review-file artifacts/e3-review-new/labels.json --vectors 'C:/path/to/public-vectors.sqlite3' --max-calls 72 --output artifacts/e3-live-new
```

可以用重复 `--case` 选择某个划分中的固定子集，先默认计划其上限。执行前预算必须覆盖该子集的两侧最坏上限；全局不超过 200。文档向量缺失/不匹配直接停止，不自动建库。每次远程派发前 fsync 记 attempt，失败也计；首个供应商错误立即停止，不退到词法后继续花判断调用，不自动重试、换型号或补跑。运行途中检索降级也停止，不能冒充同条件混合对照。

输出必须是 artifacts 下的新目录。保留已完成、未运行、错误、源码/语料/缓存哈希、每次请求哈希、响应状态、来源、停止原因和实际阶段耗时。发生意外中断时 predictions.jsonl / calls.jsonl 仍保留；不能因为没有完整报告而删掉已发生的尝试。真实正文和复核凭据只留本机，公开交付使用脱敏聚合。

## 回答复核后才计算质量

完成且源码不变的批次生成 ANSWER_REVIEW.md 和 answer-review.json。展示时隐藏方案名、打乱顺序，每条核对相关性、是否覆盖原问题、引用支持和适用范围，写 correct/incorrect 及理由；不使用模型充当额外裁判。可接受有理由的有效替代出处，不能把“命中了参考 ID”直接当答对。资料不足须明确缺证据，不可拿蛋白质食物分类冒充每日克数。

此包只隐藏方案名，维护者仍能查看原报告，不宣称独立盲测。样本 ID 和复核绑定完整报告哈希，pending、错配、缺侧、供应商失败、mock 或源码变化的报告不能产生质量提升率。

```powershell
python scripts/evaluate_knowledge_loop.py --score-report artifacts/e3-live-new/report.json --answer-review artifacts/e3-live-new/answer-review.json --output artifacts/e3-scored-new
```

分开报告可答题正确摘答、资料不足题正确停止、两侧整体正确数、未获复核认可的摘答，以及旧错新对/旧对新错和净百分点；开发/留出分开。预算和真实耗时从原报告读取，不由 answered 数量推断收益。网络错误/未运行不塞进零分后宣布完整对照，token/金额未采集填未知，45 秒不承诺强制抢占同步 I/O 或线上 SLA。
