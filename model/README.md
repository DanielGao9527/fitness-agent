# 模型与语音、图片接口

本目录封装外部 AI 服务。上层业务只通过受约束的接口发送任务，返回内容仍需经过业务校验。

| 文件 | 职责 |
| --- | --- |
| [factory.py](factory.py) | 定义模型协议、配置状态、功能开关和统一错误类型 |
| [qwen.py](qwen.py) | 千问文字请求、响应解析、超时及供应商错误分类 |
| [speech.py](speech.py) | 语音格式检查和转写服务 |
| [vision.py](vision.py) | 图片格式、大小与元数据处理，以及视觉模型请求 |

变量模板见 [../.env.example](../.env.example)，运行配置从后端进程环境读取。密钥不进入前端、Git 仓库或常规日志；文字、语音、照片等能力可分别启用。

`configured_unverified` 仅说明配置检查通过，不说明供应商已经成功生成内容。模型异常返回稳定分类供前端显示，不能把错误正文中的私密内容原样呈现给用户。

开发时优先使用 [tests/](../tests/) 中的模型替身。真实调用可能计费，也会向供应商发送任务所需信息；本模块不自动重试以隐藏失败。调用额度由 [services/usage.py](../services/usage.py) 管理，业务合法性由相应服务复核。
