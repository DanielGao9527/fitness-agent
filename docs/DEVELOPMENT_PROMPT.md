## 实现

- 保持 Python 模块直接，复用当前服务；不为学习亮点引入无用途框架或多个自治 Agent。
- 身份来自认证会话，私人档案/记忆/记录与公共知识严格分离。
- AI 输出是候选或建议；实际记录和个人事实写入需要相应的明确确认，重试不能重复写入。
- 过敏、明确禁忌、器械范围、来源版本及过期检查不得为提高成功率而放宽。
- 热状态、温记忆、冷证据按职责读取；不复制第二套权威档案，不把历史模型答案作为新知识出处。
- 文档控制开发过程；prompts 控制应用内模型行为，存在提示词不代表已接线或真实验证。

## 验证与交付

- 改账号、事实或记录时覆盖认证、跨用户、输入校验、重启、并发、撤销及旧结果失效。
- 使用隔离合成数据库；测试服务和正式进程分开，不在正式库造测试账号。
- 真实调用有明确预算和失败账本；网络/计费错误不自动续跑，模拟结果不写成模型质量。
- 留出集不用于反复调参，所有失败、未运行项和不利方案结果保留；不预设简历提升率。
- 不打印或提交密钥、令牌、密码、用户记录及图片；运行报告公开前核对内容。
- 本机 localhost:8765 的增强切换已获用户授权并已备份迁移，保持原账号、记录和额度。后续迁移仍先备份核验；不擅自购买服务或部署公网。运行版本与源码版本分别记录。
