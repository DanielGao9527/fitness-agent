## 实现

- 保持 Python 模块直接，复用当前服务；不为学习亮点引入无用途框架或多个自治 Agent。
- 身份来自认证会话，私人档案/记忆/记录与公共知识严格分离。
- AI 输出是候选或建议；实际记录和个人事实写入需要相应的明确确认，重试不能重复写入。
- 过敏、明确禁忌、器械范围、来源版本及过期检查不得为提高成功率而放宽。
- 热状态、温记忆、冷证据按职责读取；不复制第二套权威档案，不把历史模型答案作为新知识出处。
- 文档控制开发过程；prompts 控制应用内模型行为，存在提示词不代表已接线或真实验证。
