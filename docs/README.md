## 验证口径

单元及接口测试使用合成数据和模型替身；通过不等于真实模型效果、实体手机或公网环境已经验收。Linux 安装与测试以 GitHub Actions 和目标服务器的实际结果为准；部署配置文件存在也不代表服务器已接通。
