## 启动与复现

本机沿用原 fitness-agent/scripts/start.ps1，打开 http://localhost:8765；当前增强服务已运行，账号/记录仍来自原库。无密钥可用账号和手动记录，知识问答要求服务端模型配置。

离线回放：在源码目录运行 python scripts/replay_knowledge_loop.py --output artifacts/knowledge-loop-replay-new。输出需为新目录，默认不访问网络、密钥或私人数据库；虚拟环境和浏览器检查命令见 [scripts](../scripts/README.md)、[tests](../tests/README.md)。
