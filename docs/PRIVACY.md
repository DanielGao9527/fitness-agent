# 隐私与数据处理

本说明描述当前代码的数据流，部署者仍需管理服务器访问权限、供应商账户与备份存储。

## 应用保存的数据

SQLite 保存账号密码哈希、登录会话、档案、饮食训练体测记录、目标、对话、待确认草稿及调用次数。密码不以明文保存；数据库和备份本身没有自动加密，应置于受限的持久目录。

个人记忆还保存用户明确核对的交流偏好、个人术语、原话来源和版本。删除或更正来源会停用相关记忆；从对话另存的摘录是独立条目，清除其内容需在个人记忆列表删除。数据库删除账号时相关条目与计数按外键级联清理。

公开知识库仅保存资料摘要和出处，不混入私人业务记录。浏览器只获取当前已登录用户的数据，身份由后台会话决定。

反馈工作台保存本人反馈正文、原回答关联/来源指纹，以及公共摘录候选和本人审阅意见。默认只有本人可见，不上传模型或参与 RAG。个人纠正不会自动修改档案。只有本人逐条明确同意提交后，具备服务端审核权限的正式账号才可查看该公共摘录及出处；审核队列不导出私人问题、回答、反馈、本人意见或用户身份。

提交、工程检查与人工预审仍保存在私人数据库，预审通过不代表公开发布，也不会参与线上检索。删除反馈、来源对话或清理账号级联删除关联候选、提交、检查和事件；来源或内容变化后须重新核对。审核权限来自本机明确配置，每次请求重查，普通账号和游客不能自授。正式公共版本发布及回滚尚未接通。

审核人可明确构建独立候选包，保存在私人库旁 knowledge-builds 目录，仅含公共资料摘要、出处、随机提交编号和版本指纹；不包含私人问题、回答、反馈、意见或用户身份。开发回归和失败报告只保留公开案例 ID、候选 ID、判定与哈希，不上传模型。删除原反馈/对话/账号后相关包不能继续发布，但不会自动删除历史构建文件，须由本机管理员按保留策略归档或清除；这些包尚未接入在线知识库。

版本登记与事件还保留包哈希、随机版本/提交编号、检查结果及内部审核账号关联；接口不导出账号身份或私人对话。删除原资料或账号会使关联登记失效，被删除账号的内部外键清空、被删除提交的成员关联移除，保留不含正文/身份的失效事件；历史包与登记不自动物理擦除。发布登记和准备报告尚未接入在线检索。

游客档案、记录、对话和草稿只作临时保存。主动退出删除活动数据库中的对应行；连续两小时未操作或体验满一天后拒绝访问，并在运行中的后台一分钟清理周期内删除，停机期间则在下次启动时清理。浏览器异常关闭无法保证立即通知服务器。刷新页面可继续，新的访问不自动恢复临时记录；浏览器会话恢复行为可能不同，服务端最长一天的期限仍有效。

为限制接口费用，日期、网络地址哈希及游客调用计数最长保留七天，退出或新建游客不退还次数；同一网络的游客共享额度。此哈希不是匿名化承诺，不存原始地址于该表。浏览器不保存游客的业务记录，只保存本页随机证明。活动库逻辑删除不等于磁盘安全擦除，也不会自动追删先前的服务器备份或供应商留存；部署者须为私密备份设置保留周期，恢复备份后会撤销所有登录会话。

## 何时使用外部模型

启用对应能力且用户明确操作时，后台可能把完成任务所需的饮食/训练描述、相关档案条件、有限历史上下文、用户主动录制的音频或选中的饮食图片发给供应商。输入文本自身也可能包含个人信息；页面的核对与处理说明应保留。

语音转写返回输入框核对，模型解析与推荐不自动变成实际记录。普通手动记录、页面刷新和健康检查不需要调用生成模型；缺少 Key 也能运行基础账号和记录流程。

## 公开仓库排除项

- 真实 `.env`、密码、API Key、私钥和访问令牌。
- 数据库及其 WAL/SHM、上传附件、录音、运行索引、日志和备份。
- 本机虚拟环境、缓存、含私人正文的运行报告和未经筛选的交接材料。公开工程说明和合成评测结果须核对后发布。

测试使用虚构账号、合成记录和替身模型。`.env.example` 只提供占位配置；忽略规则不能抹除已经提交过的秘密，首次提交及后续每次提交都要核对内容。

## 更新和分享

更新代码不应覆盖服务器中的实际记录或环境文件。数据库备份使用私密存储，与公开代码发布分开；排障报告也需排除私人正文。公开 GitHub 仅提供源码阅读，不会授予网站账号、服务器或数据库权限。
