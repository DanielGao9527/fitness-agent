# 隐私与数据处理

本说明描述当前代码的数据流，部署者仍需管理服务器访问权限、供应商账户与备份存储。

## 应用保存的数据

SQLite 保存账号密码哈希、登录会话、档案、饮食训练体测记录、目标、对话、待确认草稿及调用次数。密码不以明文保存；数据库和备份本身没有自动加密，应置于受限的持久目录。

公开知识库仅保存资料摘要和出处，不混入私人业务记录。浏览器只获取当前已登录用户的数据，身份由后台会话决定。

## 何时使用外部模型

启用对应能力且用户明确操作时，后台可能把完成任务所需的饮食/训练描述、相关档案条件、有限历史上下文、用户主动录制的音频或选中的饮食图片发给供应商。输入文本自身也可能包含个人信息；页面的核对与处理说明应保留。

语音转写返回输入框核对，模型解析与推荐不自动变成实际记录。普通手动记录、页面刷新和健康检查不需要调用生成模型；缺少 Key 也能运行基础账号和记录流程。

## 公开仓库排除项

- 真实 `.env`、密码、API Key、私钥和访问令牌。
- 数据库及其 WAL/SHM、上传附件、录音、运行索引、日志和备份。
- 本机虚拟环境、缓存、运行报告、个人绝对路径和开发交接指令。

测试使用虚构账号、合成记录和替身模型。`.env.example` 只提供占位配置；忽略规则不能抹除已经提交过的秘密，首次提交及后续每次提交都要核对内容。

## 更新和分享

更新代码不应覆盖服务器中的实际记录或环境文件。数据库备份使用私密存储，与公开代码发布分开；排障报告也需排除私人正文。公开 GitHub 仅提供源码阅读，不会授予网站账号、服务器或数据库权限。
