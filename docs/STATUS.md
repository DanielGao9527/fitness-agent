## 可使用的真实效果证据

外部 T2 固定抽样为 100 题、1,000 文档，每篇统一前 6,000 字符，同题、同文档和同标签：

| 方案 | Recall@6 |
| --- | ---: |
| 旧双字 FTS5/BM25 | 72.11% |
| jieba FTS5/BM25 | 70.74% |
| 纯向量 | 88.51% |
| 双字＋向量 RRF | 83.29% |
| 当前 jieba＋向量 RRF | 84.16% |

相对旧双字提高 **12.05 个百分点**；该抽样中纯向量更好。这是相关文档召回，不是问答准确率或官方全库成绩。见 [实验说明](archive/2026-09/T2_RETRIEVAL_EVALUATION.md) 与 [原始结果](../evals/results/t2-pilot-2026-09-25.json)。内部 260 QA（236 可答、24 证据不足）来自审核摘要，只作项目回归，不替代外部泛化证据。

记忆首版真实千问已运行 98 组，113 次尝试、99 次响应、14 次供应商失败，另 2 组未运行；最终器械/来源匹配为 112/128＝87.50%，留出 36/48＝75.00%，没有匹配旧版本对照。固定响应回放的补问 0/15→15/15、校验候选 35/40→40/40 是相同旧响应的后端比较，不能写成模型理解率提高；原始候选 29/40、最终建议器械/来源 75/75 均未改变。见 [真实记忆报告](../evals/results/memory_v1_report_20260928/REPORT.md)、[旧响应回放](../evals/results/memory_v1_dev_replay_final_20260929/REPORT.md)。
