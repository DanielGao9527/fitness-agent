## 能力与边界

| 模块 | 已核实 | 保留的边界 |
| --- | --- | --- |
| 原业务 | 多模态核对草稿、明确确认/幂等写入、MILP多餐规划、当天训练建议 | 估算有范围和假设；无伤病一般成人；不生成做法或康复处方 |
| E1 中文检索 | jieba/FTS5/BM25＋阿里云向量、RRF、版本缓存、验源和降级 | 独立克隆不分发向量缓存；最终回答质量不等于召回率 |
| E2 个人记忆 | 会话/档案/历史证据；来源、范围、更正、删除、版本；跨会话到最终动作链路已验收 | 冷历史主要由明确回忆触发；非Hermes运行框架、非任意事实自动记忆；旧语义失败保留 |
| E3 有界检索 | 最多两轮检索/一次改写，原问题复核、额度、协作式截止与离线回放 | 不等于跨请求自学习；真实开发集没有净收益，一般问题误拦截仍在 |
| E4 知识治理 | 私人反馈→公共摘录预审→构建/登记→服务端质量报告→人工批准→切换/回滚 | 正常协议仍待独立标签/质量复核；没有实际候选发布、账号自动提权或自动知识提取 |

档案和实际记录属于私人数据库，公共知识单独管理。温记忆是用户核对的受限条目；模型不能自行覆盖权威档案。训练只安排今天、读取近七天实际完成，不把计划或建议当作已完成。

## 可使用的效果证据

**外部检索对照**：同一T2固定抽样100题、1,000文档、同标签，每篇统一前6,000字符。

| 方案 | Recall@6 |
| --- | ---: |
| 旧双字FTS5/BM25 | 72.11% |
| jieba FTS5/BM25 | 70.74% |
| 纯向量 | 88.51% |
| 双字＋向量RRF | 83.29% |
| 当前jieba＋向量RRF | 84.16% |

相对旧双字提高12.05个百分点，该抽样纯向量更高；这是相关文档召回，不是问答准确率或官方全库成绩。[方法](archive/2026-09/T2_RETRIEVAL_EVALUATION.md)与[结果](../evals/results/t2-pilot-2026-09-25.json)保留全部方案。内部260 QA是自建回归资料，不替代外部泛化证据。

**记忆同题真实对照**：项目所有者复核的24组/8族，07b6ec2与de32154统一使用qwen3.6-plus、日期/档案/目录，各版使用原有API。

| 共同指标 | 旧版 | 增强版 |
