## 可使用的效果证据

### 检索

外部 T2 固定抽样：100 题、1,000 文档，所有方案同题、同文档、同标签；每篇统一使用前 6,000 字符。

| 方案 | Recall@6 |
| --- | ---: |
| 旧双字 FTS5/BM25 | 72.11% |
| jieba FTS5/BM25 | 70.74% |
| 纯向量 | 88.51% |
| 双字＋向量 RRF | 83.29% |
| 当前 jieba＋向量 RRF | 84.16% |

当前方案相对旧双字提高 **12.05 个百分点**；纯向量在这份抽样中更好。该指标衡量已标注相关文档的召回，不是回答准确率，也不是官方全库成绩。见 [完整实验说明](archive/2026-09/T2_RETRIEVAL_EVALUATION.md) 与 [原始结果](../evals/results/t2-pilot-2026-09-25.json)。

内部 260 QA（236 可答、24 证据不足）已超过“至少 200 条”的要求，但来自审核摘要的自建题，只用于项目回归，不代替外部泛化证据。
