# 知识与第三方资料

## 数据分工

| 数据 | 文件 | 用途 |
| --- | --- | --- |
| 知识片段 | `data/knowledge/sources.json` | 资料检索、摘答及有出处的建议依据 |
| 食材参考 | `data/nutrition/reference.json` | 审核食材的成分范围、生熟口径与过敏映射 |
| 动作目录 | `data/training/exercises.json` | 动作、器械条件、模式与出处 |
| 结构参考 | `data/training/systems.json` | 三/四/五分化等结构资料及项目改编说明 |

知识索引由应用在运行目录生成，属于可重建文件。个人档案、实际饮食训练记录和对话保存在私人业务库，不放入公共知识目录。

## 收录原则

资料记录来源、定位、审核日期、适用范围及复核期限。运行时过滤未审核、过期或撤回内容；缺少资料时返回明确缺口，不用模型或实时网络搜索补成既定事实。未核实的研究候选不随公开版本发布，也不进入运行时索引。

营养参考使用有出处的成分表及明确代理关系，保留食材、生熟状态和份量口径。目录不是全量热量库；实际描述的模型估算仍需标注范围与假设，不冒充称量结果。

动作与结构资料只提供当前已整理范围。器械、时间、经验和实际历史仍由业务服务核对；有来源不等于适合任意个人，更不代表医疗或康复处方。

## 资料来源与许可

食材参考包含 CoFID 2021 的整理数据，原资料来源与 OGL 说明保留在数据元信息中。[原始数据发布页](https://www.gov.uk/government/publications/composition-of-foods-integrated-dataset-cofid)

训练与公共知识保留各自原始网页/手册定位，只收录必要事实摘要，不复制整本课程、整站内容或手册插图。各来源的权利和使用条件分别适用，不能把仓库公开理解为全部第三方资料采用统一开源许可。

三份训练参考笔记保留动作、组次及不确定性说明，以已整理文字资料列入知识库，不包含附件、图片指纹或私人来源标记。原始发布者、作者归属与完整课程仍未核实，不提供虚构原文网址或声称开放许可。原始资料未写组次而由产品规则补充时必须明确区分；原资料力竭和周期加重建议不直接开放执行。

前端图标依赖的许可见 [LICENSE.lucide](../static/vendor/LICENSE.lucide)。项目没有代替第三方授予额外许可。

## 更新方式

修改公共 JSON 前先核对原资料及复核日期，保留稳定标识和出处；同步更新目录/策略版本并运行相关测试。旧对话建议保留为历史，但不能沿用失效资料继续生成新建议。来源数量和版本以当前数据文件为准，避免文档中再维护一份容易过时的计数。
